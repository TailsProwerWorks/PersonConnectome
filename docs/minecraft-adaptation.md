# Minecraft reference adaptation to People Playground

Reviewed 2026-09-12 against [fly-brain-minecraft](https://github.com/blendi-remade/fly-brain-minecraft), particularly [WorldSenses](https://github.com/blendi-remade/fly-brain-minecraft/blob/main/src/main/java/com/fruitfly/entity/WorldSenses.java), [SensoryEncoders](https://github.com/blendi-remade/fly-brain-minecraft/blob/main/src/main/java/com/fruitfly/brain/SensoryEncoders.java), [MotorMap](https://github.com/blendi-remade/fly-brain-minecraft/blob/main/src/main/java/com/fruitfly/brain/MotorMap.java), [MotorDecoder](https://github.com/blendi-remade/fly-brain-minecraft/blob/main/src/main/java/com/fruitfly/brain/MotorDecoder.java), [FlyEntity](https://github.com/blendi-remade/fly-brain-minecraft/blob/main/src/main/java/com/fruitfly/entity/FlyEntity.java) and [LifNetwork](https://github.com/blendi-remade/fly-brain-minecraft/blob/main/src/main/java/com/fruitfly/brain/LifNetwork.java).

The transferable sensory and motor choices are adapted within the existing C# runtime. The reference also contains fly-specific gameplay, hand-authored Minecraft cues and a different neural integrator. Copying these would not make a People Playground Human biologically accurate. The table records the reviewed feature families and the actual boundary; it is not a claim that every upstream feature is implemented.

| Reference feature | PersonConnectome implementation or limit |
|---|---|
| Real connectome and neural visualizer | Existing pinned MaleCNS derivative and authoritative LifBrain retained. All finite soma coordinates and captured spikes remain in the Canvas UI. No generated/demo replacement. |
| Damage response | Added an edge sample from valid connected-limb health loss and a one-shot previously tracked limb-loss event. Hill-derived amplitude reaches tactile/bristle populations. Native pain and adrenaline remain separate game readings, not a simulated feeling. |
| Regional touch | Head, arm, leg and core contacts use native flags and disjoint existing nerve/type annotations. Human-to-fly regions are engineering analogies. Broad impact/vibration and injury merge by maximum. |
| Audio bands and direction | One accepted external source supplies world-X bearing plus coarse source-spectrum energy below/above 100 Hz when Unity supplies it. Empty/invalid spectra fall back to broad playback. No song, word or sound-identity recognition, head-relative ears or 3D localization. |
| Light and ON/OFF | Ambient grayscale plus the strongest supported nearby native light-sprite estimate and scalar ON/OFF transitions. No spatial retinal ray grid, per-column color, UV, exact beam textures/shadows or invented dark tonic drive. |
| Looming and small moving objects | Added five-band head-relative frontal-field selection, independent per-side maximum pooling, and analytic bounds/velocity size, expansion and sweep features for LC4/LPLC2 and LC11/LC18. Actual head angular velocity contributes to relative sweep. No semantic LC10a tracking or rendered retinal motion is claimed. |
| Optic motion | Added light-gated VS input from native body angular speed. Unsigned 2D body-rotation proxy, not 3D roll/yaw optic flow. |
| Joint, gravity and temperature | Existing finite connected-joint position/speed/load, native tilt and hot/cold proxies retained. Wind is not inferred from world velocity. |
| Smell, taste, humidity and grooming dirt | Native chemical senses remain unmapped; stock Pumpkin has explicitly labeled proximity/head-contact gameplay routes to selected olfactory/gustatory populations (see [details](food-escape-blood.md)). Minecraft's item/block/biome/rain mappings do not provide native chemical concentrations, taste receptors or humidity in People Playground. Internal liquids remain exposure telemetry; wetness is not humidity. No chemical identity is invented from a syringe name. |
| Walking, backward and turning readout | Added 150 ms forward/backward/leg and 100 ms turn filters, walking-mode hysteresis/dwell, immediate backward priority and immediate halt/brake. Turning becomes human head/core joint requests; actual head pose changes visual selection and bearing on the next sample. The local 0.3 active walk floor is an actuator setting, not an increase in displayed neural activity. |
| Flight, landing, wingbeat and giant-fiber jumps | No human-wing equivalent and no added force/physics injection. Relevant neurons remain in the graph but do not create these actions. |
| Feeding, hunger, proboscis, grooming, courtship and song | No equivalent supported person actuator/state model is added. MN9 does not become human grasping; unavailable actions remain unmapped. |
| Fly reflex controller, autonomous escape/hover/swim | Looming still enters LC4/LPLC2 before the graph is read. An actual `DNp01` spike is shown as raw activity; it contributes a neural escape request and a bounded 0.6-second native walking burst only with recent threat evidence, while native body hazards remain a separate safety input. The reference also has an optional random exploration/odor-steering fallback in FlyBody; this is hand-built behavior, not neural firing. No independent oscillator, random exploration fallback, sensor-selected escape direction, jump force or hover/swim autopilot is introduced. |
| Upstream continuous dynamics and encoders | Retained the discrete 20 Hz default, threshold/decay/refractory/delay model and bounded scheduler. No 0.5 ms integrator, Poisson-rate encoder, general adaptation model, physiological Hz claim or upstream validation equivalence. Only the injury encoder adapts the Hill response shape. |
| Networking, persistence and parallel fly simulation | No networking, saved brain state or new worker-thread simulation. Game APIs continue to run on the existing control loop. |

[Exact selectors, formulas and full-graph measurements](sensory-mapping.md) distinguish source annotations, native observations and engineered transformations. [API compatibility](api-compatibility.md) records the game boundary. [Manual acceptance](manual-game-test.md) is still needed for native rendering, sound spectra, movement and performance. The scheduler integrates all eligible active inputs and caps propagation at 24,000 spikes. The current 25-case report has no dropped spikes, but stronger/custom workloads may exceed the cap. Wiring tests do not establish effective walking or faithful biology.

Escape qualification update (2026-09-14): raw DNp01 spikes remain visible, but only qualify an avoidance request with recent injury/body-hazard/effective-looming evidence and movement permission. This intentionally adds a local Human gameplay gate to the reference-style spike readout; it does not alter neural firing or prove causality. Manual visual overrides are reflected in the effective looming diagnostic.
