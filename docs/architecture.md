# Architecture

The runtime brain has one implementation: `Mod/RuntimeBrain.cs`. The game compiles and loads that file directly, while the .NET source project and runtime tests compile the same physical file as a linked source. `Mod/script.cs` only registers the Human variation and creates the brain after the game-specific asset loader succeeds. The remaining `Mod` files are integration code for People Playground/Unity sensing, actuation, asset decoding and display; they do not contain a second neural controller.

The former standalone `src/PersonConnectome` offline library and its contract-test project were removed because the game never compiled or loaded them. The shipped game path is now the `Mod/` project, with runtime and adapter tests using the same shipped source files and narrow game/Unity doubles. There is one authoritative brain implementation rather than a parallel offline engine.

The shipped asset is a thresholded MaleCNS v1.0 derivative: 176,422 neurons, 6,287,749 retained connections (weight >=5, self-edges excluded). It is not the full released connection graph. The PNG carries the exact compressed FLYB bytes. Runtime verifies SHA-256, dataset identity, exact counts, CSR structure, target and used metadata indexes before caching shared graph arrays. Each person has independent dynamic neural state.

At each control tick, the adapter reconciles surviving/new limbs and builds a fresh bounded sensory frame. Heuristic sensory populations receive weighted game signals; nearby direction and liquid healing feed the command decoder only. Vision is a bounded line-of-sight/light proxy, while vibration, proprioception, falling, projectile awareness and ambient heat/cold are bounded mechanical/body-state channels. Ambient temperature comes from the native `AmbientTemperatureGridBehaviour` at the person location; dynamic nearby physical objects and native lava components add distance-attenuated thermal cues, while static map geometry is not mistaken for a cold object. The neutral ambient calibration leaves the default 20 setting unstimulating. These are not invented radiation or wall-penetrating heat. Falling reads downward velocity from each tracked limb's native physical body and is suppressed by floor contact; it is not fabricated from horizontal walking or unrelated child bodies. Visual target labels are conservative metadata, not semantic recognition. Sparse LIF processing caps work at 24,000 active neurons, rotates overloaded work, merges carried input with new propagation and expires refractory periods by neural tick. Telemetry exposes queued input targets, active/processed/deferred work, spikes and whether the scheduler is steady or backlogged. This bounds neuron work, not a guaranteed frame-time budget or biological fidelity.

Terminal/invalid frames clear neural state and stop commands. Motor cleanup sets joint influence to one even for incapable limbs, drops grips and restores only owned regeneration boosts. Nonterminal unconsciousness is sampled but motor/chemistry commands are suppressed. Recovery from terminal state starts from cleared state. The controller processes at most one neural tick per physics callback and clamps excess elapsed time to prevent catch-up spikes.

The independent overhead label displays requested versus applied commands and follows the current head/root without inheriting ragdoll mirroring. It has no physics/control responsibility. No game persistence is implemented; reusable-library state tests do not establish Unity save compatibility.
